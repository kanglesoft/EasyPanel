{{* ---------- Webhook ---------- *}}
仅支持 http/https。面板跑在 kangle 容器内：要打宿主服务请用 host.docker.internal（compose 已配 extra_hosts），写 127.0.0.1 只会连到容器自己。
GET 时正文改为查询串（title / content），不发送请求体。
占位符：{title} / {content}；JSON 内需自行处理引号用 {title_json} / {content_json}。JSON 格式下模板解析失败会自动回落默认载荷。
Content-Type 由正文格式自动设置；Content-Length / Host / Connection 填写会被忽略。
填写后随请求附带 X-Ep-Signature: sha256=<hmac(body)> 与 X-Ep-Timestamp，接收端据此校验来源。
{{* ---------- SMTP ---------- *}}
国内邮箱（QQ / 163 / exmail）这里填的是SMTP 授权码，不是登录密码。
多数邮箱服务商强制发件人与登录账号一致，否则会被拒收或进垃圾箱。
非法地址会被自动剔除；全部非法时保存被拒绝。正文为纯文本 + UTF-8（quoted-printable）。
{{* ---------- Telegram ---------- *}}
Token 属机密，保存后不再回显。
私聊为正数，群组 / 超级群组为负数，频道为 @频道名。开启 Topics 的群可填 message_thread_id。
正文一律自动转义后再套格式，无需担心尖括号破坏排版。
1~30 秒，留空或超范围按 10 秒。一次事件向多个渠道投递时各自独立计时。
